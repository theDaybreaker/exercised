<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| YouTube caption API → server | Unofficial endpoint; response may contain arbitrary text |
| OpenAI API → generateText | LLM output; constrained by Structured Outputs but still untrusted until Zod-validated |
| transcript → sourceQuote validator | Transcript is external data; normalize() handles encoding variance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Information Disclosure | OPENAI_API_KEY in lib/ai/extract.ts | mitigate | Key accessed only via process.env.OPENAI_API_KEY in the @ai-sdk/openai provider; never logged or serialized |
| T-02-03-02 | Tampering | LLM output → WorkoutSchema | mitigate | Output.object({ schema: WorkoutSchema }) enforces grammar-level schema conformance; OpenAI Structured Outputs prevents malformed JSON |
| T-02-03-03 | Spoofing | Fabricated sourceQuote | mitigate | validateSourceQuotes drops exercises where sourceQuote does not appear in the transcript (D-22 hallucination guard) |
| T-02-03-04 | Denial of Service | generateText with very long transcript | accept | Vercel maxDuration=300 terminates hung requests; OpenAI API has its own timeouts; transcript length is bounded by YouTube caption limits |
| T-02-03-SC | Tampering | npm/pip/cargo installs | accept | Packages installed in Plan 02-02 after human spot-check; no new installs in this plan |
</threat_model>
