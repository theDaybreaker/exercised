<objective>
Build the eval set (D-21) that gates the real-pipeline release. A human checkpoint selects 9 YouTube URLs, then Claude builds the expected-output JSON files and the eval runner. The eval runner must exit non-zero if any binary criterion fails. pnpm eval passing is the ship gate for Plan 02-07.

The eval runner independently verifies sourceQuote substring matches by re-fetching captions via getCaptions() and re-running validateSourceQuotes() — it does not trust the server-side guard alone (D-21c requires independent verification).

Purpose: No real OpenAI key can be activated until the eval set passes binary criteria. This is the mechanism that prevents shipping a pipeline that hallucinates or fabricates workouts. The non-fitness control test is the single most important criterion — failing it means the system returns fabricated workouts for non-workout videos.

Output: 9 eval fixture files + 1 smoke.json + tests/eval/run.ts executable as pnpm eval.
</objective>
