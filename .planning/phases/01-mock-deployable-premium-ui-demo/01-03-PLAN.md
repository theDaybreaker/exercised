D-17 verbatim:
> Long-workout fallback: if `lz-string(workout)` compressed payload exceeds 2KB, strip optional fields from the share payload in this order: `sourceQuote`, `form_cues`, `equipment[]` — keeping name, sets, reps, rest, supersets, header. UI surfaces a single-line notice on the share success toast: "Share link omits form cues for length."

D-18 verbatim:
> Share URL is schema-versioned — payload includes `schema_version` from the locked schema. If a recipient opens a share URL with a future-incompatible schema version, the app shows an honest error: "This share link was created with a newer version of Exercised — try pasting the original YouTube URL instead." Same-version older links always work.

D-17 toast copy variants (Plan 3 discretion within the verbatim "omits X for length" pattern):
- stripped includes only `sourceQuote` → "Share link omits source quotes for length."
- stripped includes `form_cues` (with or without sourceQuote) → "Share link omits form cues for length." (this is the verbatim spec line — covers the common case)
- stripped includes `equipment` (the rarest, deepest strip) → "Share link omits source quotes, form cues, and equipment for length."

THRESHOLD: 2048 chars of `compressToEncodedURIComponent` output (D-17). Plan 1's `lib/share/encode.ts` already exports `const MAX_PAYLOAD_BYTES = 2048` but never iterates the strip chain.

Recipient-side rendering (UI-SPEC §11 verbatim):
> 3. If payload was stripped per D-17 (>2KB), render inline notice above the workout header: 'Share link omits form cues for length.' in Label style, --text-muted, with a small Info icon

Decode return shape: `decodeShareUrl(encoded: string): { workout: Workout; stripped: StripField[] }` — Plan 1 returned just `Workout`; Plan 3 extends to return the strip-flag info. The strip info is NOT encoded in the URL itself (the URL already lacks the stripped fields); it is INFERRED by comparing the decoded workout's optional fields. A reasonable inference: if the decoded workout has ANY exercise where `sourceQuote === null` AND `form_cues.length === 0` AND `equipment.length === 0`, we can't tell whether those were stripped or just unset; instead, encode the strip-info AS PART OF THE PAYLOAD as a `_stripped: string[]` field on the wire object, and strip it from the decoded `Workout` before returning. Schema-compat: add `_stripped` as an OPTIONAL untyped sibling of the workout payload, NOT inside `WorkoutSchema`. Use a wrapper schema `SharePayloadSchema = z.object({ workout: WorkoutSchema, stripped: z.array(z.enum(["sourceQuote","form_cues","equipment"])).default([]) })` and encode/decode against THAT wrapper. (This is cleaner than mutating WorkoutSchema.)

**Update `lib/share/encode.ts`** to implement the full RESEARCH §"Code Examples / Share-URL Encode/Decode" strip-chain. Replace Plan 1's TODO stub with:
```ts
const STRIP_ORDER: StripField[] = ["sourceQuote", "form_cues", "equipment"];
const MAX_PAYLOAD_BYTES = 2048;

export function encodeShareUrl(workout: Workout): { encoded: string; stripped: StripField[] } {
  const strippedFields: StripField[] = [];
  let candidate = workout;

  for (let attempt = 0; attempt <= STRIP_ORDER.length; attempt++) {
    const payload: SharePayload = { workout: candidate, stripped: strippedFields };
    const json = JSON.stringify(payload);
    const compressed = LZString.compressToEncodedURIComponent(json);
    if (compressed.length <= MAX_PAYLOAD_BYTES || attempt === STRIP_ORDER.length) {
      return { encoded: compressed, stripped: strippedFields };
    }
    const field = STRIP_ORDER[attempt];
    strippedFields.push(field);
    candidate = stripField(candidate, field);
  }
  throw new Error("encodeShareUrl: unreachable");
}

function stripField(w: Workout, field: StripField): Workout {
  return {
    ...w,
    routine: w.routine.map((item) => {
      if (item.type === "standard_set") {
        if (field === "sourceQuote") return { ...item, sourceQuote: null };
        if (field === "form_cues") return { ...item, form_cues: [] };
        if (field === "equipment") return { ...item, equipment: [] };
        return item;
      }
      // superset — strip inner exercises
      return {
        ...item,
        exercises: item.exercises.map((ex) => {
          if (field === "sourceQuote") return { ...ex, sourceQuote: null };
          if (field === "form_cues") return { ...ex, form_cues: [] };
          if (field === "equipment") return { ...ex, equipment: [] };
          return ex;
        }),
      };
    }),
  };
}
```

**Update `lib/share/decode.ts`** to return the new shape:
```ts
export function decodeShareUrl(encoded: string): { workout: Workout; stripped: StripField[] } {
  const json = LZString.decompressFromEncodedURIComponent(encoded);
  if (!json) throw new Error("Invalid share link");
  if (json.length > 50_000) throw new Error("Share link payload too large");
  let parsed: unknown;
  try { parsed = JSON.parse(json); } catch { throw new Error("Invalid share link payload"); }

  // Try as SharePayload (Plan 3 wire shape)
  const wrapperResult = SharePayloadSchema.safeParse(parsed);
  if (wrapperResult.success) return wrapperResult.data;

  // D-18 schema-version mismatch (check the wrapper's nested workout.schema_version OR a bare workout)
  const checkVersionIssues = (err: typeof wrapperResult["error"]) => {
    return err.issues.find(i =>
      i.path.join(".") === "workout.schema_version" || i.path[0] === "schema_version"
    );
  };
  if (checkVersionIssues(wrapperResult.error)) {
    throw new Error("This share link was created with a newer version of Exercised — try pasting the original YouTube URL instead.");
  }
  throw new Error("Share link payload failed validation");
}
```
